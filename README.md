# Musesick

**Online Streaming App — Listen to music, ad-free.**

> Powered by the YouTube API. No ads, no subscriptions, just music.

## Features

### Import Playlists from YouTube
Import playlists straight from YouTube Music using just the playlist URL.

<img width="220" alt="Import playlist" src="https://github.com/user-attachments/assets/8ed799e8-4c18-4fd5-829b-7032e2d78040" />

### Local Music Player
Musesick doubles as a fully-featured local music player.

<img width="220" alt="Local player" src="https://github.com/user-attachments/assets/6f6b4953-6e44-486b-ba27-f6aabc3f8b45" />

### Export Playlists as JSON
Never lose a playlist — export it as a JSON file for safekeeping or backup.

<img width="280" alt="Export playlists" src="https://github.com/user-attachments/assets/c2be9867-788d-4abc-8347-ef7abbe3c14f" />

### In-App Updates
Update Musesick directly from the app whenever a new release drops.
